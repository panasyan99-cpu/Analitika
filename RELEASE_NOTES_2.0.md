# Analitika Web 2.0

## Назначение релиза

Версия 2.0 объединяет внешний вид всего сайта в одну продуктовую систему. Бизнес-логика анализа, сравнения, заказа поставщику, Sonu и Baserow не изменялась.

## Дополнение Order Completion Repair

- закрытие исторического завершённого заказа больше не переводит его обратно в черновик;
- при открытии заказа из библиотеки статус «завершён» сверяется с сохранённым состоянием до любой записи в облако;
- старый заказ `заказnew.xlsx` автоматически восстанавливается как завершённый;
- для жемчужного подраздела фиксируется дата отправки **24.07.2026**;
- для каменного подраздела фиксируется дата отправки **25.07.2026**;
- миграция ограничена именем файла и контрольными итогами заказа, поэтому другие заказы не изменяются;
- версия сайта остаётся **2.0**.

## Дополнение Secure Order Timeline

- сайт защищён общим паролем из Streamlit Secrets; пароль не хранится в исходном коде;
- после пяти неверных попыток вход временно блокируется, а после длительного бездействия сессия завершается;
- галочка получения заменена на четыре статуса: «Заказ отправлен», «Заказ в работе», «Shipping», «Получен»;
- для каждого этапа сохраняется собственная дата и показывается единая история движения заказа;
- даты проверяются на хронологическую последовательность;
- все статусы до получения остаются жёлтыми, полученный заказ становится зелёным;
- статусы и даты каменного и жемчужного подразделов независимы;
- в ручном заказе количество изделий стало обязательным;
- ручные заказы поддерживают те же статусы, даты и редактирование истории;
- ручной заказ теперь можно редактировать без удаления: название, дата отправки, количество и комментарий;
- после добавления ручного заказа форма очищается полностью;
- обновлено PDF-руководство пользователя;
- отображаемая версия остаётся **2.0**.

## Дополнение Delivery Tracking & PDF Guide

- основной экран «О программе» начинается сразу с пяти возможностей системы;
- вкладка «Руководство» по-прежнему открывается с главы «Быстрый старт»;
- полное руководство доступно для скачивания как оформленный PDF с обложкой, оглавлением, колонтитулами и нумерацией страниц;
- история обновлений сохранена отдельной третьей вкладкой без сокращения;
- завершённые заказы «Камни» и «Жемчуг» по умолчанию имеют жёлтый статус «В пути»;
- галочка «Получено» переводит соответствующую карточку в зелёный статус, сохраняет дату и синхронизируется через Cloudflare R2;
- статус каждого подраздела независим: получение камней не меняет статус жемчуга и наоборот;
- добавлен ручной журнал ожидаемых поставок с названием, датой, комментарием, отметкой получения и удалением;
- обе кнопки «Открыть заказ» оформлены как основные золотые действия, а «Информация по заказу» — как вторичные белые;
- внутренняя и отображаемая версия остаётся **2.0**.

## Основные изменения 2.0

- управленческие описания всех модулей;
- единые шапки, карточки, формы, таблицы, графики и уведомления;
- полное удаление legacy-боковой панели;
- понятная иерархия основных и вторичных действий;
- компактные состояния загруженного отчёта;
- единая адаптивность для ПК, iPad и смартфонов;
- визуальная доработка общего анализа, сравнения, заказа поставщику, Sonu, Baserow и страницы «О программе».

## Совместимость

- Streamlit 1.60.0;
- PyArrow 24.0.0;
- Python 3.12;
- до 150 МБ на один загружаемый файл.
