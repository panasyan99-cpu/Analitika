# Analitika Web 2.0

## Назначение релиза

Версия 2.0 объединяет внешний вид всего сайта в одну продуктовую систему. Бизнес-логика анализа, сравнения, заказа поставщику, Sonu и Baserow не изменялась.

## Основные изменения

- управленческие описания всех модулей;
- единые шапки, карточки, формы, таблицы, графики и уведомления;
- полное удаление legacy-боковой панели;
- понятная иерархия основных и вторичных действий;
- компактные состояния загруженного отчёта и пустые экраны;
- единая адаптивность для ПК, iPad и смартфонов;
- визуальная доработка общего анализа, сравнения, заказа поставщику, Sonu, Baserow и страницы «О программе».

## Совместимость

- Streamlit 1.60.0;
- PyArrow 24.0.0;
- Python 3.12;
- до 150 МБ на один загружаемый файл.
