# Analitika Web 2.4.0 — полный безопасный склад

## Главное

- добавлен мастер создания и миграции таблицы «Позиции поставок»;
- добавлены служебные поля операций и поставок;
- миграция повторяемая и не дублирует существующие строки;
- неоднозначные старые SKU помечаются «Требует проверки»;
- поставки, приёмка и передача используют только безопасную модель данных;
- коробки больше не считаются постоянным свойством товара;
- добавлен отчёт миграции в JSON;
- Baserow-пароль не сохраняется: он используется только для короткого JWT;
- исправлены релизные тесты и зафиксирована версия 2.4.0.

## Включённые предыдущие обновления

- 2.1.0 — фото и новый пользовательский интерфейс склада;
- 2.2.0 — безопасные позиции поставок и надёжность операций;
- 2.3.0 — производительность, строгая валидация и улучшение UX;
- 2.4.0 — схема, миграция, диагностика и техническая стабилизация.

## Первый production-запуск

После развёртывания откройте **История → Обслуживание** и один раз запустите
**«Создать и мигрировать»**. Для изменения структуры Baserow требуется короткая
авторизация Builder/Admin; Database Token отвечает только за рабочие операции
со строками. После успешного запуска сайт автоматически определит ID таблицы.
