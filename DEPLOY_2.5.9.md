# Deploy Analitika Web 2.5.9

1. Сделайте резервную копию текущего приватного репозитория.
2. Распакуйте архив поверх версии `2.5.8 STABLE RESTORED`.
3. Не заменяйте действующие Streamlit Secrets для `[auth]` и `[order_storage]`.
4. Встроенное подключение Baserow оставьте без изменений.
5. Выполните:

```bash
git add -A
git commit -m "fix: make supplier orders and Sonu decisions reliably persistent"
git push
```

После деплоя проверьте:

- открытие и сохранение одного тестового черновика заказа поставщику;
- кнопку «Проверить облако снова» при временной ошибке R2;
- сохранение одного ручного решения браслета Sonu и повторное открытие страницы.
