# Analitika Web 1.10.0

## Аналитика завершённых заказов

- Заказы по камням и жемчугу из одного исходного отчёта считаются отдельными заказами и отображаются внутри одного общего блока.
- Каждый тип заказа завершается независимо собственной кнопкой.
- В истории заказов добавлена кнопка «Информация по заказу».
- Все итоги аналитики считаются в штуках, а не по количеству SKU.
- Для заказа по камням показываются общий итог, номенклатурные группы, блоки «Топовые камни» и «Цветные камни», семьи и конкретные камни.
- Для жемчуга показываются общий итог, номенклатурные группы и детализация по видам жемчуга.
- Limited Order отображается отдельно и не включается в количество основного заказа.
- Логика рекомендаций не изменялась и будет пересмотрена отдельной версией.
