# Развёртывание Analitika Web 1.11.1

1. Распакуйте архив.
2. Скопируйте всё содержимое папки репозитория поверх текущего репозитория Analitika.
3. Не удаляйте существующие Streamlit Secrets.
4. Выполните:

```bash
git add -A
git commit -m "Analitika Web 1.11.1 - Remove analytics sidebar and expand user guidance"
git push
```

5. Дождитесь зелёного GitHub Actions.
6. Streamlit Community Cloud автоматически подтянет commit. При необходимости выполните **Manage app → Reboot app**.
7. В интерфейсе и логах проверьте версию `1.11.1`.

## Быстрая проверка после публикации

- В общем анализе и сравнении нет чёрной левой панели навигации.
- Металл, пробы и курс находятся внутри «Настройки отчёта».
- В каждом рабочем модуле есть вкладка «Как с этим работать».
- Кнопки замены отчёта доступны в основной области.
- «О программе → Руководство» содержит расширенные главы по всем модулям.
