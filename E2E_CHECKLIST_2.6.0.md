# Browser E2E checklist — Analitika Web 2.6.0

## Безопасный smoke на рабочем сайте

- Вход по общему паролю.
- Открытие: «Обычный отчет», «Сравнение периодов», «Сувениры и касты на складе», «Заказ Sonu», «Заказ поставщику», «О программе».
- В складе: «Главная», «Товары», «Поставки», «История», «Диагностика».
- Нажатие «Проверить всё снова» в диагностике.
- Отсутствие `stException`, Traceback и аварийной страницы.

Автоматизация: `python scripts/e2e_smoke.py`.

## Проверка на staging-копии Baserow/R2

### Заказ поставщику

1. Сохранение при доступных SQLite и R2.
2. Сохранение при временно недоступном R2: локальная запись подтверждена, облачная ошибка показана честно.
3. Одновременная ошибка SQLite и R2: заказ помечен как несохранённый, закрытие блокируется.
4. После восстановления R2 кнопка повторной проверки меняет статус без деплоя.
5. После перезапуска активный заказ и история доступны.

### Sonu

1. Сохранить ручное решение.
2. Перезапустить приложение или выполнить новый деплой.
3. Убедиться, что решение загружено из R2.
4. Проверить предупреждение при сохранении только локальной резервной копии.

### Склад

1. Открытие страницы не создаёт таблицы и поля автоматически.
2. Диагностика показывает точный план отсутствующих полей.
3. Без подтверждения схема не меняется.
4. После подтверждения схема исправляется один раз и повторная проверка зелёная.
5. При token с чтением, но без записи, рабочие кнопки заблокированы.
6. Проверить загрузку фотографии.
7. Импортировать поставку, искусственно прервать обработку после нескольких SKU, затем продолжить.
8. Убедиться, что SKU, карточки, строки поставки и операции не продублировались.
9. Провести обычную приёмку, приёмку по весу, передачу в бухгалтерию и обратную корректировку.
10. Повторно отправить тот же Command ID и убедиться в идемпотентности.
11. Проверить журнал действий в диагностике.

### Большие файлы

1. Открыть рабочий Excel размером около 95 МБ.
2. Проверить общий анализ, сравнение периодов и заказ поставщику.
3. Убедиться, что предыдущий тяжёлый расчёт освобождается после перехода к новому файлу.
4. Проверить понятное сообщение при реальной нехватке ресурсов, без бесконечной загрузки.
