# Установка patch 2.5.11

База установки: **Analitika Web 2.5.10**.

1. Сделайте резервную копию текущего репозитория.
2. Скопируйте содержимое папки `files/` из patch-пакета в корень репозитория с заменой файлов.
3. Новые файлы также должны быть добавлены в Git.
4. Выполните:

```bash
pytest -q test_management_report_2510.py test_store_63_2511.py
```

5. Запустите приложение и проверьте:
   - курс виден в «Управленческом отчете»;
   - деньги в таблицах и диаграммах показаны в USD;
   - 63 Timing и 63 Retail разделены в аналитике;
   - в «Заказе поставщику» отображается один остаток 63.

Рекомендуемый commit:

```text
fix: convert management analytics to USD and split store 63
```
