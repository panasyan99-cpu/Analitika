# Analitika Web 1.11.2

## Единый рабочий интерфейс

- Удалены активные чёрные боковые панели из заказа поставщику, заказа Sonu и склада Baserow.
- Общий анализ, сравнение, Sonu, заказ поставщику и Baserow теперь используют одну схему: вкладки «Работа» / «Как с этим работать», затем компактные параметры и основная рабочая область.
- Действия из боковых панелей перенесены внутрь страницы: смена файла Sonu, сохранение заказа, статус Baserow.

## Курс и пробы

- Блок «Настройки отчёта» переименован в «Курс и пробы» во всех рабочих модулях.
- Блок показывается только на вкладке «Работа».
- Для каждого модуля добавлено пояснение, какие параметры реально влияют на расчёты.

## Сравнение периодов

- Удалена повторяющаяся верхняя плашка «Сравнение двух периодов».
- Удалено лишнее уведомление о необходимости отправить два файла; форма сама показывает два обязательных поля.

## Руководство пользователя

- Разделы заказа поставщику, Sonu и Baserow расширены до уровня управленческой инструкции.
- Добавлены формулы, последовательность обработки, приоритеты правил, контрольные примеры, типовые причины необычных результатов и списки проверки перед принятием решения.

## Совместимость

- Бизнес-логика рекомендаций и расчётов не изменялась.
- Streamlit 1.60.0, PyArrow 24.0.0.
- Максимальный размер файла — 150 МБ.
