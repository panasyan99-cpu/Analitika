# Установка Analitika Web 1.10.1

Это полный репозиторий релиза. Отдельно устанавливать 1.10.0 не требуется: функциональность 1.10.0 уже включена.

## 1. Сделать резервную копию

Перед заменой файлов сохраните текущий репозиторий или создайте отдельную ветку/тег.

```bash
git status
git add .
git commit -m "Backup before Analitika Web 1.10.1"
```

## 2. Заменить файлы проекта

Скопируйте содержимое папки `Analitika_Web_1.10.1_RECOMMENDATIONS` в корень действующего репозитория.

Не удаляйте:

- служебную папку `.git`;
- реальные секреты Streamlit;
- настройки Cloudflare R2 / S3 из панели приложения.

Файл `.streamlit/secrets.toml.example` является только примером и не содержит рабочих ключей.

## 3. Установить зависимости и проверить локально

```bash
pip install -r requirements.txt
python -m py_compile streamlit_app.py src/order_workflow.py
pytest -q
streamlit run streamlit_app.py
```

Ожидаемый результат автоматических тестов релиза:

```text
181 passed, 1 skipped
```

## 4. Проверить заказ поставщику

Минимальный приёмочный сценарий:

1. Загрузить четырёхмесячный отчёт.
2. Открыть заказ по камням.
3. Переключить базовый и сезонный режимы.
4. Проверить карточки серёг при TT 0/1/2/3+.
5. Для серёг выбрать `Заказать другой замок` и скачать основной Excel.
6. Проверить колонку `Change Lock To`.
7. Проверить кольца, подвески и предупреждение возможного дубля крестика.
8. Завершить тестовый заказ и убедиться, что история и аналитика открываются отдельно для камней и жемчуга.

## 5. Опубликовать

```bash
git add .
git commit -m "Release Analitika Web 1.10.1"
git push origin main
```

Streamlit Cloud пересоберёт приложение по существующему URL.

## Совместимость черновиков

Черновики предыдущих версий мигрируют до `DRAFT_VERSION = 6`. Новые поля режима рекомендаций и замены замка добавляются без удаления ранее сохранённых количеств, размеров колец и Limited Order.
