# Analitika Web 2.5.5

## Проверка двух форматов серебряного Invoice

Проверены оба поддерживаемых формата:

- расширенный Invoice 18.07.2026 с готовой закупкой USD;
- исходный Invoice 30.06.2026 с закупочными ценами в RMB.

Оба формата создают только ожидаемую поставку. Строки не отмечаются принятыми, фактическое количество пустое, остатки меняются только позднее через «Приёмка → По поставке».

## Хотфикс цены 30.06

В исходном Invoice значения `silver/g`, `labour/g`, `price/g` и `Amount` являются закупочными ценами в RMB. Дополнительные 11% CIF больше не начисляются.

Формулы:

- закупка USD/ед. = `Amount RMB / 6.71 / Quantity`;
- продажа USD = `закупка USD/ед. × 10`;
- продажа VND = `закупка USD/ед. × 10 × 26 500`, затем округление вверх до 1 000 VND.

Для расширенного Invoice готовая закупка USD сохраняется без пересчёта.
