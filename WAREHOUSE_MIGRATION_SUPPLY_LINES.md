# Миграция склада: таблица «Позиции поставок»

Онлайн-модуль уже работает с существующими таблицами Baserow в режиме
совместимости. Для корректной истории повторяющихся SKU рекомендуется создать
пятую таблицу.

## Таблица

Название: `Позиции поставок`

| Поле | Тип Baserow | Назначение |
|---|---|---|
| Строка поставки | Primary text | `SUP-... — SKU` |
| Поставка | Link to table → Поставки | Родительская поставка |
| Товар сувенирки | Link to table → Сувенирка | Карточка SKU |
| Комплектующее | Link to table → Комплектующие | Для будущих поставок кастов |
| По документу, шт. | Number, integer | Количество этой строки |
| Принято, шт. | Number, integer | Принято по этой строке |
| Передано в бухгалтерию, шт. | Number, integer | Уже передано |
| Номера коробок | Long text | Коробки только этой поставки |
| Статус | Single select | Ожидается / Частично получена / Получена полностью / Отменена |
| Комментарий | Long text | Служебная информация |
| Версия | Number, integer | Для защиты от одновременного изменения |
| Активна | Boolean | Активность строки |

После создания укажите ID таблицы в Streamlit Secrets:

```toml
[baserow]
supply_lines_table_id = 646
```

До этого момента сайт:

- разрешает работу по старой структуре;
- блокирует повторное создание уже существующей поставки;
- предупреждает о SKU, связанных с другой поставкой;
- рассчитывает доступное к передаче количество как принятое минус уже
  переданное по `ID поставки`;
- не удаляет проведённые операции физически.
