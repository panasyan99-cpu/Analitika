# Release Notes — Analitika Web 2.5.2

## Исправление регистрации серебряной поставки

- Серебряный импорт больше не отправляет значение `Аксессуары` в старое поле Baserow `Категория`.
- Классификация серебра сохраняется только в отдельном поле `Серебряная категория`.
- Это устраняет ошибку Baserow `ERROR_REQUEST_BODY_VALIDATION` / `not a valid select option` при создании поставки.
- Обычные поставки комплектующих продолжают использовать старое поле `Категория` без изменений.

## Диагностика

- Убрано предупреждение Streamlit о конфликте `default` и Session State у навигационных переключателей склада.
- ISO-даты `YYYY-MM-DD` теперь разбираются явно, без предупреждения pandas о `dayfirst=True`.
