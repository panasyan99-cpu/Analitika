# Развёртывание Analitika Web 2.0 — Delivery Tracking & PDF Guide

Это дополненная сборка того же релиза **2.0**. Номер версии не повышается.

1. Распакуйте архив.
2. Скопируйте **всё содержимое** папки репозитория поверх текущего репозитория.
3. Не удаляйте существующие Streamlit Secrets: они нужны для Cloudflare R2 и Baserow.
4. Выполните:

```bash
git add -A
git commit -m "Analitika Web 2.0 - Add delivery tracking and PDF user guide"
git push
```

5. Дождитесь зелёного GitHub Actions.
6. В Streamlit Cloud выполните **Manage app → Reboot app**.

После запуска проверьте:

- в интерфейсе отображается версия **2.0**;
- на странице «О программе» первым показан блок «Возможности»;
- во вкладке «Руководство» работает скачивание `Analitika_USER_GUIDE.pdf`;
- у завершённых заказов камней и жемчуга отображается жёлтый статус «В пути»;
- галочка «Получено» переводит выбранную карточку в зелёный статус;
- ручной заказ в пути сохраняется и виден после перезагрузки страницы.
