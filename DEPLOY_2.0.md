# Развёртывание Analitika Web 2.0 — Secure Order Timeline

Это дополненная сборка того же релиза **2.0**. Номер версии не повышается.

1. Распакуйте архив.
2. Скопируйте **всё содержимое** папки репозитория поверх текущего репозитория.
3. Не удаляйте существующие Streamlit Secrets: они нужны для Cloudflare R2 и Baserow.
4. В Streamlit Cloud откройте **Settings → Secrets** и добавьте блок доступа:

```toml
[auth]
password = "<ОБЩИЙ_ПАРОЛЬ>"
```

Пароль не хранится в репозитории. Для локального запуска можно использовать переменную окружения `ANALITIKA_APP_PASSWORD`.

5. Выполните:

```bash
git add -A
git commit -m "Analitika Web 2.0 - Edit manual orders and update delivery stages"
git push
```

6. Дождитесь зелёного GitHub Actions.
7. В Streamlit Cloud выполните **Manage app → Reboot app**.

После запуска проверьте:

- при открытии ссылки сначала появляется экран пароля;
- после правильного пароля открывается Analitika Web 2.0;
- завершённые заказы имеют выпадающие статусы «Заказ отправлен», «Заказ в работе», «Shipping», «Получен»;
- при выборе нового статуса можно указать даты этапов;
- до получения карточки жёлтые, после получения — зелёные;
- камни и жемчуг отслеживаются независимо;
- при ручном добавлении заказа обязательно указывается количество изделий;
- ручной заказ можно открыть через «Редактировать заказ» и изменить без удаления;
- после добавления заказа поля формы очищаются;
- история статусов сохраняется после перезагрузки и на другом устройстве;
- PDF-руководство скачивается из раздела «О программе».
