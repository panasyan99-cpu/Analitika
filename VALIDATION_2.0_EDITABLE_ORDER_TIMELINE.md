# Проверка Analitika Web 2.0 — Editable Order Timeline

## Что проверено

- версия приложения остаётся `2.0`;
- пользовательские статусы: «Заказ отправлен», «Заказ в работе», «Shipping», «Получен»;
- старые внутренние значения `approved` и `in_progress` читаются без миграции данных;
- ручной заказ редактируется без изменения `order_id`;
- редактирование сохраняет текущий статус и историю дат;
- изменение даты отправки обновляет первый этап и проверяет хронологию;
- количество изделий остаётся обязательным и должно быть больше нуля;
- форма добавления очищается на следующем rerun до создания виджетов;
- PDF-руководство содержит обновлённые статусы и описание редактирования;
- код компилируется, полный набор тестов проходит.

## Результат

- `247 passed`;
- `3 skipped` — Streamlit AppTest, недоступные в локальной среде проверки;
- PDF: 34 страницы, визуально проверен после повторного рендера.
