# Deploy 2.5.15

1. Распакуйте архив в чистую папку или замените файлы репозитория содержимым архива.
2. Проверьте, что `version.json` содержит версию `2.5.15`.
3. Установите зависимости из `requirements.txt` в среде приложения.
4. Запустите приложение обычной командой проекта.
5. В разделе «Управленческий отчет» загрузите по три отчета для каждого периода.
6. Убедитесь, что после блока «Продажи по поставщикам» страница заканчивается и раздела «Комплексный анализ итогов трех блоков» больше нет.

Рекомендуемый коммит:

```bash
git add -A
git commit -m "ui: remove combined management comparison block"
git push
```
