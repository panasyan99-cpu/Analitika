# Analitika Web 2.5.6

## Повторная проверка серебряных Invoice

Поддерживаются два фиксированных формата:

- расширенный Invoice 18.07.2026: 18 позиций, готовая закупка USD, пусеты учитываются парами, цепочка №11 продаётся отдельно;
- исходный Invoice 30.06.2026: 14 позиций, 14 фотографий, закупочные цены в RMB и автоматическая классификация согласованных групп.

Оба формата создают только ожидаемую поставку. При регистрации: `Получено = 0`, фактическое количество пустое, приходных операций нет. Физическая приёмка выполняется позже через «Приёмка → По поставке» после ручного пересчёта.

## Контроль закупочных цен 30.06

Перед созданием поставки проверяется арифметика каждой строки:

- `silver/g + labour/g = price/g`;
- `Weight × price/g = Amount`.

При несоответствии импорт блокируется с указанием номера строки и ошибочных значений.

Формулы цены:

- закупка USD/ед. = `Amount RMB / 6.71 / Quantity`;
- продажа USD = `закупка USD/ед. × 10`;
- продажа VND = `закупка USD/ед. × 10 × 26 500`, округление вверх до 1 000 VND.

Если оператор корректирует закупку USD до создания поставки, поля исторической продажи при импорте теперь синхронно пересчитываются. Для расширенного Invoice 18.07 исходные исторические цены из файла сохраняются без изменения.
