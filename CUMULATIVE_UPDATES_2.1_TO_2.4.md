# История обновлений склада: 2.1.0 → 2.4.4

## 2.1.0

- реальные фотографии в каталоге, поставках, приёмке и передаче;
- защищённая загрузка приватных файлов Baserow;
- новая навигация: Главная, Товары, Поставки, Передача, История;
- карточки товаров и поставок;
- компактные предупреждения и удобные рабочие сценарии.

## 2.2.0

- отдельная таблица «Позиции поставок»;
- связь операции с конкретной строкой поставки;
- Command ID и защита от двойного проведения;
- статусы проведения и восстановление после частичного сбоя;
- безопасные корректировки и ограничение повторной отмены;
- поставки комплектующих.

## 2.3.0

- локальная очистка складских кэшей;
- строгие обязательные колонки Excel;
- раннее отображение превышения остатка;
- автоматический номер поставки;
- ранняя проверка дублей SKU;
- архивные карточки;
- временные файлы вместо постоянного хранения Excel в памяти;
- очистка временных каталогов.

## 2.4.0

- автоматическое создание схемы Baserow через защищённый мастер;
- миграция существующих поставок;
- отчёт неоднозначных старых данных;
- служебные поля операций и импортов;
- полная блокировка небезопасной старой записи;
- единая версия и зелёный набор тестов.

## 2.4.1

- исправлен сбой Streamlit при программном переходе между складскими вкладками;
- добавлена безопасная очередь навигации между rerun.

## 2.4.2

- версии 2.4.0 и 2.4.1 возвращены в видимую историю обновлений;
- вкладка обслуживания удалена;
- Baserow-схема проверяется автоматически;
- рабочие данные Baserow хранятся в приватных Secrets;
- оператор получает права записи, руководство — только просмотр;
- JWT рабочего аккаунта автоматически обновляется.

## 2.4.3

- восстановлен прежний вход на сайт только по общему паролю;
- формы email и отдельного пароля удалены с главного экрана;
- авторизация Baserow выполняется автоматически при открытии склада.

## 2.4.4 — Производительность операций и контроль количества

- ленивое переключение способов передачи без одновременного выполнения всех вкладок;
- крупные фото и пагинация рабочих таблиц;
- визуально выделенные поля редактирования количества;
- индивидуальный жёсткий максимум для каждой позиции;
- автоматическое ограничение Excel-количества текущим остатком;
- повторное использование строк Baserow в рамках одного рендера.
