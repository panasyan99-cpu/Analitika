# Analitika Web 1.9.8 — Supplier Excel and Stock Notice

## Основные Excel-заказы

Изменения применены только к итоговым Excel-файлам двух режимов:

- «Камни»;
- «Жемчуг».

В этих файлах:

- удалён столбец группы изделия (`Ring`, `Earrings`, `Pendant` и другие);
- заголовки переведены на английский: `Photo`, `SKU`, `Stone`, `Order Quantity`, `Sizes`;
- значения внутри строк не переводятся.

`Limited Order` и все остальные отчёты сохранены без изменений.

## Остаток при распределении колец

Для позиции с доступным остатком теперь выводится только информационное уведомление. Галочка «С остатком сверился» удалена, а отсутствие подтверждения больше не блокирует выгрузку.

Скачивание основного Excel остаётся недоступным только при незавершённом распределении заказанного количества колец по размерам.
