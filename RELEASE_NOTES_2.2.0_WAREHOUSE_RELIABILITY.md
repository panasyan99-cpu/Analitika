# Analitika Web 2.2.0 — надёжность склада

Обновление включено в итоговый релиз 2.4.0.

- обязательная таблица «Позиции поставок»;
- количество, приёмка, передача и коробки хранятся по строке поставки;
- старый режим совместимости удалён;
- приёмка и передача получили Command ID и защиту от повторного проведения;
- операция получает статус «Создаётся», «Проведена» или «Требует восстановления»;
- корректировки связываются с исходной операцией;
- повторная корректировка ограничена оставшимся количеством;
- деактивация товара учитывает операции и позиции поставок;
- добавлена поддержка поставок комплектующих.
