# Analitika Web 1.9.9 — Remove Ring from Order

## Размеры колец

Под блоком выбора размеров каждой заказанной позиции-кольца добавлена кнопка **«Удалить из заказа»**.

После нажатия:

- количество позиции в заказе становится равным нулю;
- сохранённое распределение по размерам очищается;
- ручное состояние позиции очищается;
- карточка сразу исчезает после перезапуска интерфейса;
- позиция не учитывается в общей сводке и не попадает в основной Excel.

Изменение не затрагивает Limited Order и другие отчёты.
