# Деплой Analitika Web 2.5.10

1. Распакуйте архив поверх приватного репозитория.
2. Не заменяйте рабочие настройки Streamlit и Baserow.
3. Выполните:

```bash
git add -A
git commit -m "fix: parse full 1C sales reports exactly and stop false supplier analytics"
git push
```

После деплоя загрузите июньский и июльский полные отчёты в «Сравнение периодов» и проверьте разделы «Магазины», «Продавцы» и «Ассортимент».

В разделе «Поставщики» для полного отчёта без уровня `Поставщик` должно появляться информационное сообщение, а не ошибочный график. Для поставщиков нужен отдельный отчёт 1С с поставщиком в строке иерархии.
