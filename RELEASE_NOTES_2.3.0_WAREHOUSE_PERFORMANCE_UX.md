# Analitika Web 2.3.0 — скорость и UX склада

Обновление включено в итоговый релиз 2.4.0.

- фотографии показываются через защищённые серверные миниатюры;
- склад разделён на понятные рабочие пространства;
- автосохранение черновика приёмки в текущей сессии;
- строгая проверка Excel: без обязательных заголовков импорт останавливается;
- превышение остатка видно до проведения;
- автоматический номер поставки `SUP-YYYYMMDD-NNN`;
- дубли SKU показываются до создания поставки;
- временные файлы старше 24 часов очищаются;
- склад очищает только собственные кэши и не сбрасывает анализ, SONU и заказы;
- архивные карточки скрыты по умолчанию.
