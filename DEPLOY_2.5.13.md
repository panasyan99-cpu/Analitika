
## После деплоя

В разделе **«Управленческий отчет»** для каждого периода должны отображаться три загрузчика:

- ПРОД;
- КОНС;
- ПОСТ.

Всего для сравнения двух периодов загружается шесть файлов.

## Контрольный сценарий

1. Загрузить `ИЮНЬПРОД`, `ИЮНЬКОНС`, `ИЮНЬПОСТ` в первый период.
2. Загрузить `ИЮЛЬПРОД`, `ИЮЛЬКОНС`, `ИЮЛЬПОСТ` во второй период.
3. Построить отчет.
4. Проверить июльский блок Own production: **839 единиц**, **1 702 807 500 VND** до конвертации в USD.
5. В комплексном контроле для ПРОД, КОНС и ПОСТ должны быть нулевые расхождения общей выручки, точного количества и возвратов.

## Важное ограничение

Не смешивайте файлы разных периодов. Сайт проверяет даты внутри каждого набора и остановит построение при несовпадении.
