# Analitika Web 2.5.13

## Назначение релиза

Управленческий отчет переведен на три независимые выгрузки 1С для каждого периода:

- **ПРОД** — общие продажи по магазинам;
- **КОНС** — продажи по консультантам;
- **ПОСТ** — продажи по поставщикам.

Сначала сайт строит самостоятельную аналитику каждого блока, затем выполняет комплексную сверку и объединенный анализ итогов.

## Исправлено

- Общая выручка, количество и возвраты больше не вычисляются суммированием вложенных строк. Источник KPI — явная строка **«Итого»** каждого файла.
- Устранено занижение блока консультантов: строки `Admin` и пустой менеджер сохраняются в контрольном total и отображаются отдельно.
- Поставщики читаются только из отдельного файла ПОСТ. Определение по похожим SKU и семействам артикулов в управленческом отчете не используется.
- `Own production service` нормализуется в `Own production`.
- Сохраняется строка **«Не определен»** для продаж без заполненного поставщика в выгрузке ПОСТ.
- Добавлена проверка, что ПРОД, КОНС и ПОСТ внутри одного периода имеют одинаковые даты и совпадают по выручке, точному количеству и возвратам.
- Добавлена отдельная внутренняя сверка каждого блока: сумма главного разреза против строки «Итого».
- Учтено округление весовых количеств в групповых строках 1С: точный KPI всегда берется из «Итого», допустимое отклонение группировки показывается в технической сверке.
- В аналитике магазинов `63 Retail` и `63 Timing` остаются раздельными.

## Структура отчета

1. Аналитика ПРОД: KPI, магазины, камни/вставки, пробы, номенклатурные группы.
2. Аналитика КОНС: KPI, консультанты, возвраты, пробы и группы.
3. Аналитика ПОСТ: KPI, поставщики, Own production и номенклатурные группы.
4. Комплексный контроль трех блоков и объединенные драйверы изменения.
