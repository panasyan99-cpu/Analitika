# Analitika Web 2.4.1 — срочное исправление склада

## Исправлено

После обновления страницы и нажатия «Перейти в обслуживание» Streamlit мог остановить складской раздел с `StreamlitAPIException`. Причина: код менял `warehouse_workspace` после того, как переключатель с этим ключом уже был создан в текущем rerun.

В 2.4.1 переходы записываются во временную очередь и применяются в самом начале следующего rerun — до создания виджетов.

Защищены сценарии:

- Передача → История → Обслуживание;
- карточка каталога → Управление → Редактировать;
- новая поставка → Реестр после успешного создания;
- программные переходы между подразделами склада.

## Бизнес-логика

Приёмка, передача, позиции поставок, операции, остатки и миграция Baserow не изменялись. Релиз включает все обновления 2.1.0–2.4.0.
