# Analitika Web 2.4.2

## Рабочий аккаунт

- Добавлен отдельный оператор склада.
- Оператор входит по email и паролю и получает права на создание и изменение складских данных.
- Руководители продолжают использовать общий пароль сайта и получают режим «Только просмотр».
- В режиме просмотра скрыты создание поставок, приёмка, передача, управление карточками и корректировки.

## Автоматический Baserow

- Вкладка «Обслуживание» удалена из пользовательского интерфейса.
- Рабочие реквизиты Baserow читаются только из приватных Streamlit Secrets.
- При входе оператора сайт автоматически проверяет таблицу «Позиции поставок».
- Если таблица или служебные поля отсутствуют, повторяемая миграция запускается автоматически.
- Для Warehouse API используется короткий JWT рабочего аккаунта с автоматическим обновлением.

## История обновлений

- Исправлены заголовки CHANGELOG.md.
- Версии 2.4.0 и 2.4.1 снова видны в «О программе → История обновлений».
- Добавлена версия 2.4.2.
- Сохранена накопительная история 2.1.0–2.4.1.

## Совместимость

- Аналитика, сравнение периодов, Sonu и заказ поставщику не менялись.
- Позиции поставок, Command ID, строгая проверка Excel и hotfix навигации сохранены.
