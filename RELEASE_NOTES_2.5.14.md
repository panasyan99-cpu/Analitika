# Analitika Web 2.5.14

## Изменения

- Три блока управленческого отчета названы по назначению: «Продажи по магазинам», «Продажи по консультантам», «Продажи по поставщикам».
- Название загружаемого Excel-файла может быть любым. Тип отчета проверяется по его структуре и группировкам 1С.
- Во всех сравнительных таблицах управленческого отчета положительные значения разницы выделяются зеленым, отрицательные — красным.
- Такое же цветовое правило добавлено в общие сравнительные таблицы сайта.
- Цвет отражает математический знак разницы, без инверсии для скидок или возвратов.
- Все отображаемые суммы USD в основной аналитике, управленческом отчете и аналитике Sonu округляются до ближайших 10 долларов. Исходные VND и расчеты не меняются.
- Порядок блоков: магазины → консультанты → поставщики; после них остается комплексная сверка трех источников.

## Совместимость

Логика чтения трех отдельных отчетов, поставщиков, консультантов, магазинов, возвратов и строки «Итого» сохранена из 2.5.13. Склад, Baserow и «Заказ поставщику» не изменялись. В Sonu изменено только отображение USD; расчеты и рекомендации не менялись.
