# Analitika Web 2.0.1 — фотографии на складе

## Исправлено

- каталог по умолчанию открывается карточками с реальными фотографиями;
- в табличном виде добавлена полноценная колонка изображений;
- фото отображается в карточке редактирования и перед удалением;
- фотографию товара можно заменить из веб-интерфейса;
- в реестре выбранной поставки показываются фото всех SKU;
- фото добавлены в приёмку по поставке и ручной приход;
- фото добавлены в передачу по поставке, по SKU и из Excel;
- предупреждение о низком остатке также показывает изображение;
- Master/Packing List показывает извлечённые фотографии прямо в редактируемой таблице;
- локальные изображения Master преобразуются в компактные миниатюры, чтобы не перегружать страницу;
- карточки каталога имеют пагинацию 6/12/18 и серверный кэш изображений.

## Производительность

Полные фотографии не помещаются в Session State. Для таблицы Master создаются только миниатюры 190×190, а карточки каталога показываются постранично.
