# Развёртывание Analitika Web 1.11.0

1. Распакуйте архив.
2. Скопируйте **всё содержимое** папки `Analitika_Web_1.11.0_ANALYTICS_UX` в корень репозитория с заменой файлов.
3. Не удаляйте `.streamlit/secrets.toml` в Streamlit Cloud: секреты не входят в архив.
4. Выполните:

```bash
git add -A
git commit -m "Analitika Web 1.11.0 - Redesign analytics and comparison UX"
git push
```

5. Дождитесь зелёного GitHub Actions.
6. В Streamlit Cloud откройте **Manage app → Reboot app**.
7. В логах проверьте:

```text
Streamlit version 1.60.0
pyarrow==24.0.0
```

8. На сайте проверьте отображение версии `1.11.0`.

## Быстрая приёмка

- Общий анализ: загрузка → короткая сводка → переключение пяти рабочих разделов.
- Лидер розничной сети не должен быть OUTLET или 63.
- В Обзоре полная таблица магазинов закрыта по умолчанию.
- Сравнение: загрузка двух периодов → четыре карточки → семь рабочих разделов.
- Драйверы: порог 3%, графики роста/снижения, статусы новых и исчезнувших групп.
- О программе: Обзор → Руководство → История обновлений.
- Проверка ширины: 1440 px, 1024×768, 820×1180, 390×844.
