# Analitika Web 2.4.4

## Исправлено зависание передачи

Раньше `st.tabs` выполнял код всех трёх способов передачи при каждом перезапуске страницы. Одновременно загружались поставки, весь каталог, операции и множество фотографий. Теперь используется ленивый переключатель: выполняется только выбранный способ.

## Жёсткие ограничения количества

- по поставке: максимум равен минимуму из доступного количества этой поставки и текущего складского остатка;
- по отдельному SKU: максимум равен текущему остатку;
- при приёмке: максимум равен количеству, которое ещё ожидается по строке поставки;
- из Excel: завышенное значение автоматически уменьшается до остатка.

Поле количества выделено золотым цветом и подписано.

## Фото и скорость

- миниатюры увеличены до 320 px;
- строки таблиц увеличены до 138 px;
- рабочие списки разбиты на страницы;
- изображения загружаются только для текущей страницы;
- данные одной таблицы Baserow повторно используются внутри текущего рендера;
- при включённой таблице «Позиции поставок» больше не загружается лишний полный журнал операций для расчёта передачи.

Релиз включает все изменения 2.1.0–2.4.3.
