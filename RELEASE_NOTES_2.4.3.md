# Analitika Web 2.4.3

## Вход на сайт

- На главном экране снова только одно поле «Пароль».
- Email Baserow больше не запрашивается у пользователя.
- Прежний общий пароль сайта не изменён.

## Склад

- Реквизиты Baserow загружаются из приватной серверной конфигурации.
- При открытии раздела «Сувениры и касты на складе» приложение автоматически получает JWT Baserow.
- JWT обновляется автоматически при истечении срока.
- Дополнительные формы входа и обслуживания не требуются.

## Накопительные изменения

Релиз содержит все обновления 2.1.0–2.4.2, включая фотографии, новый UX, позиции поставок, безопасные корректировки, строгий Excel, миграцию Baserow и hotfix навигации.
