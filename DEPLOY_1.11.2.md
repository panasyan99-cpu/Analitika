# Развёртывание Analitika Web 1.11.2

1. Скопируйте содержимое полного репозитория поверх текущего репозитория.
2. Не копируйте локальные `.streamlit/secrets.toml`, базы и runtime-файлы из другого окружения.
3. Выполните:

```bash
git add -A
git commit -m "Analitika Web 1.11.2 - Remove module sidebars and unify course and purity guidance"
git push
```

4. Дождитесь зелёного GitHub Actions.
5. Streamlit Community Cloud автоматически подтянет изменения. При необходимости выполните **Manage app → Reboot app**.

## Проверка после публикации

- версия в интерфейсе: 1.11.2;
- в каждом рабочем модуле есть вкладки «Работа» и «Как с этим работать»;
- блок называется «Курс и пробы»;
- чёрная боковая панель не появляется в Sonu, заказе поставщику и Baserow;
- в сравнении сразу видна форма двух файлов без повторяющейся информационной плашки;
- в Sonu кнопка «Загрузить другой отчет» находится в рабочей области;
- в заказе поставщику видна кнопка «Сохранить сейчас»;
- Baserow показывает статус подключения внутри страницы.
