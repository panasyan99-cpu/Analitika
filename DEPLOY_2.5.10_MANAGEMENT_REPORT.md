# Deploy Analitika Web 2.5.10

1. Сделайте резервную копию действующей версии `2.5.9`.
2. Распакуйте архив поверх репозитория `2.5.9 CLOUD RELIABILITY`.
3. Не переносите файлы из версии `2.6.0`.
4. Сохраните действующие Streamlit Secrets `[auth]`, `[order_storage]` и Baserow.
5. Выполните:

```bash
git add -A
git commit -m "feat: add management comparison report on stable 2.5.9 base"
git push
```

После деплоя:

- откройте «Управленческий отчет»;
- проверьте вкладку с инструкцией и оба скриншота;
- загрузите июнь и июль за 1–30 число;
- сверьте выручку `26 626 829 577` и `31 918 314 500` VND;
- проверьте открытие складского раздела и одного сохраненного заказа поставщику.
