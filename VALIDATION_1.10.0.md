# Validation 1.10.0

Проверено:

- завершение заказа «Камни» не изменяет статус заказа «Жемчуг» и наоборот;
- два заказа одного исходного отчёта отображаются в одном блоке с отдельными статусами;
- завершённые заказы доступны в истории по умолчанию;
- кнопка «Информация по заказу» раскрывает аналитику без перевода заказа обратно в черновик;
- количество считается в штуках по сохранённым значениям `draft.orders`, а не по числу SKU и не по рекомендациям;
- Limited Order исключён из количественных итогов и показывается отдельно;
- камни разделяются на топовые и цветные, затем на аналитические семьи и конкретные названия;
- жемчуг разделяется по видам с разрезом номенклатурных групп;
- логика рекомендаций и формулы текущей версии не изменены;
- полный набор автоматических тестов проходит успешно.
