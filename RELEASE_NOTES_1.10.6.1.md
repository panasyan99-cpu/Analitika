# Analitika Web 1.10.6.1

Hotfix развёртывания без изменения бизнес-логики заказа.

## Исправления

- `streamlit==1.60.0` совместим с закреплённым `pyarrow==24.0.0`.
- Переключатель типа заказа больше не получает одновременно `default` и значение из `st.session_state`.
- `src.warehouse` устойчивее импортируется при полном и частичном перезапуске приложения.
- Добавлены регрессионные проверки зависимостей и конфигурации переключателя.

Все изменения производительности, фрагменты, облачное автосохранение и ограничения памяти из 1.10.6 сохранены.
