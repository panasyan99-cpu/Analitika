# Analitika Web 2.5.15

## Изменение управленческого отчета

Управленческий отчет теперь заканчивается сразу после третьего самостоятельного блока — **«Продажи по поставщикам»**.

Удален весь нижний раздел **«Комплексный анализ итогов трех блоков»**, включая:

- открытые контрольные таблицы сопоставления трех файлов;
- итоговое управленческое резюме;
- общий рейтинг положительных и отрицательных драйверов из разных блоков;
- технический expander в конце страницы.

Остались три полноценные независимые части:

1. Продажи по магазинам.
2. Продажи по консультантам.
3. Продажи по поставщикам.

## Что не изменилось

- Для двух периодов по-прежнему загружаются шесть файлов.
- Имя Excel-файла может быть любым; тип проверяется по структуре выгрузки 1С.
- До построения отчета сайт продолжает проверять совпадение дат, общей выручки, точного количества и возвратов внутри каждого периода.
- Положительная динамика выделяется зеленым, отрицательная — красным.
- Отображаемые суммы USD округляются до ближайших 10 долларов; исходные VND и вычисления не округляются.
- Поставщики берутся только из отдельного отчета по поставщикам.
- `Own production service` отображается как `Own production`.
- 63 Retail и 63 Timing остаются раздельными в аналитике.
- Склад, Baserow, Sonu и «Заказ поставщику» не изменялись.
